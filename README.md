# 🐍 Python Conditional Statements

## 📌 Project Overview

This project contains Python programs that demonstrate the use of conditional statements to solve basic programming problems.

## 📚 Programs Included

1. Voting Eligibility Checker
2. Greatest of Three Numbers
3. Student Marks, Percentage, and Grade Calculator
4. Positive, Negative, or Zero Checker
5. Username and Password Validation
6. Delivery Charge Calculator
7. Decimal Formatting

## 🛠️ Technologies Used

* Python 3
* If, Elif, and Else Statements
* Nested If Statements
* Logical Operators
* Variables and Operators
* User Input and Type Conversion
* String Formatting

## 🎯 Learning Objectives

* Understand conditional statements in Python.
* Apply decision-making logic to real-world problems.
* Compare numbers using logical operators.
* Calculate marks, percentages, and grades.
* Validate user credentials.
* Calculate delivery charges based on bill amounts.

## ▶️ How to Run

1. Install Python 3.

2. Download or clone this repository.

3. Open the project in VS Code.

4. Run the following command:

   ```bash
   python conditional_statements.py
   ```

5. Enter the required values when prompted.
